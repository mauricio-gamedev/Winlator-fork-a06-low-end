# Fork do Winlator otimizada para o Galaxy A06 4G

O objetivo é criar uma versão Android leve para executar programas Windows, visual novels, point-and-click, jogos 2D/pixel art e alguns jogos 3D leves.

O aparelho de referência é o Galaxy A06 4G, com Helio G85 e 4 GB de RAM.

## Plano

- Preservar compatibilidade com a base Winlator.
- Criar perfis por tipo de aplicativo.
- Medir desempenho e estabilidade no A06 antes de alterar componentes centrais.
- Gerar APKs remotamente pelo GitHub Actions, sem exigir um computador local.

A fonte upstream usada como base é https://github.com/brunodev85/winlator-app.
